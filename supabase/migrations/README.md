# Migrations

Ordered, forward-only local migrations currently cover M2–M9: authoritative schema,
integrity/indexes, public projections, RLS/grants/authorization, transactional property-draft
services, controlled media/private-document storage, the scoped verification workflow and the
atomic property publication gate/indexability source. They have been exercised only against the
isolated local Supabase project; no production migration is authorized or recorded.
