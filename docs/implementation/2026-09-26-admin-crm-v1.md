## B. Workflow Improvements

- **Leads:** compact desktop table, mobile cards, clearer customer/requirement/budget/stage/next-action context, global search, and secondary destructive actions.
- **Follow-ups:** canonical Overdue, Today, Upcoming, and Completed queues with counts, call/WhatsApp actions, completion, and rescheduling links. Open work is no longer displaced by completed-history query limits.
- **Matching:** the lead workspace now searches available inventory by text, category, and transaction instead of relying on a capped reference dropdown. Existing matches stay visible and removable.
- **Site visits:** the queue now keeps visit, schedule, customer, property, next action, contact, and workspace links together.
- **Sellers:** “Seller enquiries” is the consistent operational label. The queue explains the private-to-draft-to-published journey and retains review/conversion controls.
- **Properties:** compact desktop inventory table, mobile cards, clearer publication/availability/media states, and less-prominent delete actions.
- **Verification:** a concise evidence queue with progress badges and explicit language that progress is not a legal conclusion.
- **Publishing:** the existing readiness and publish/unpublish logic is preserved; verification is now directly reachable from the property workspace.

## C. Public Website Improvements

- The existing public visual system, property search, category routes, privacy-aware listing language, and seller/requirement calls to action were preserved.
- Desktop, tablet, and mobile browser QA confirmed the public homepage remains responsive with no horizontal overflow at the tested tablet width.
- Admin inventory and publishing workflows now expose the public-site path more clearly without changing public claims or publication rules.

## D. Routes Consolidated

- `/admin/leads?view=follow-ups` redirects to `/admin/follow-ups`.
- `/admin/leads?view=site-visits` redirects to `/admin/site-visits` and preserves supported filters.
- `/admin/leads?view=stages` redirects to `/admin/leads/pipeline`.
- The grouped sidebar and CRM workspace tabs now identify these routes as the canonical destinations.

## F. Backend Changes

- Added exact lead-stage counts for the dashboard.
- Added exact draft, published, and off-market inventory counts.
- Added bounded, database-filtered property search for lead matching, with batched offer/unit/district lookups.
- Split follow-up retrieval into open-work and recent-completed queries so completed history cannot hide actionable work.
- Included lead phone in follow-up queue results.
- Corrected seller-enquiry next-action parsing to use the shared India-local-to-UTC conversion.

No auth, RLS, schema, publishing state machine, or database architecture was replaced.
